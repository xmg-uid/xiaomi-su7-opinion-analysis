# 小米汽车燃爆事件民众舆情分析研究

一份关于「小米 SU7 燃爆事件」的**民众舆情分析**课程研究项目。
项目以微博平台上的相关帖子与评论为数据来源，综合运用**数据爬取、情感分析、话题分类、机器学习建模**等方法，刻画该事件在社交平台上的公众情绪与讨论结构。

> 本仓库已做开源分享前的整理：清理了冗余文件、规范了目录结构，并对作者信息做了匿名化处理，便于直接推送到 GitHub。

## 🛠 环境依赖

主要使用 Python 3.8+，核心库见 `requirements.txt`。不同模块用到的库略有差异：

- **数据爬取**：`requests`、`beautifulsoup4`、`DrissionPage`
- **情感分析**：`jieba`、`snownlp`、`wordcloud`、`matplotlib`、`seaborn`
- **话题分类 / 机器学习**：`bertopic`、`sentence-transformers`、`umap-learn`、`scikit-learn`、`xgboost`、`gensim`、`torch`
- **通用**：`pandas`、`numpy`、`scipy`

安装：

```bash
pip install -r requirements.txt
```

部分依赖（如 `torch`、`tensorflow`、`bertopic`）体积较大，可按需仅安装自己所运行模块需要的库。

## ▶ 运行方式

各模块以 Jupyter Notebook 形式组织，建议用 Jupyter Lab / Notebook 依次打开：

```bash
pip install jupyterlab
jupyter lab
```

然后按需打开 `程序代码及数据/<成员>/代码/*.ipynb`，按顺序执行单元格即可。
原始代码中的个人绝对路径（如本机 Desktop 下的文件路径）已统一替换为项目内的相对路径 `data/`，实际数据均位于各成员的 `数据及结果/` 目录下。
